
#### 2. PostgreSQL не принимает TCP/IP подключения
Если подключение всё равно не работает, проверьте конфигурацию PostgreSQL внутри контейнера.

1. Подключитесь к контейнеру `postgresql`:
   ```bash
   docker exec -it postgresql bash
   ```
2. Найдите файл `postgresql.conf` (обычно в `/pgdata`):
   ```bash
   cat /pgdata/postgresql.conf | grep listen_addresses
   ```
   Убедитесь, что там указано:
   ```
   listen_addresses = '*'
   ```
   Если параметр закомментирован или установлен в `localhost`, измените его. Для этого отредактируйте файл (например, с помощью `nano`):
   ```bash
   nano /pgdata/postgresql.conf
   ```
3. Проверьте файл `pg_hba.conf`:
   ```bash
   cat /pgdata/pg_hba.conf
   ```
   Убедитесь, что есть строка, разрешающая подключения:
   ```
   host    all             all             0.0.0.0/0               md5
   ```
   Если её нет, добавьте (с помощью `nano` или `echo`):
   ```bash
   echo "host    all             all             0.0.0.0/0               md5" >> /pgdata/pg_hba.conf
   ```
4. Перезапустите контейнер:
   ```bash
   docker-compose restart postgresql
   ```
